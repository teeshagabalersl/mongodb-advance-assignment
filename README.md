# MongoDB Advanced Assignment

This repository contains the completed MongoDB Advanced assignment covering schema validation, advanced queries, aggregation, indexing, TTL indexes, backup and restore, and advanced MongoDB concepts.

## Files

- `mongodb-advanced-assignment.js` — MongoDB commands for Tasks 1–5.
- `backup-restore-commands.txt` — Backup and restore commands for Task 6.
- `answers.md` — MCQ answers for Task 7.

## Topics Covered

- Schema validation
- Advanced array queries and updates
- Bulk write operations
- Aggregation using `$lookup`, `$unwind`, and `$facet`
- Compound indexes and query performance
- TTL indexes
- Backup and restore
- MongoDB advanced concepts
